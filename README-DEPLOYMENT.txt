# Tennis Mesocycle Training Program — Updated Source

This package updates the shared background and visual treatment across all site sections.

## Included
- `index.html` — original content, navigation, editing controls, and scripts with the shared tennis-court background theme.
- `assets/tennis-court-background.jpg` — bundled background image.
- `netlify/functions/videos.mts` — original Netlify Blobs video function, unchanged.
- `netlify.toml`, `package.json`, and `package-lock.json` — original Netlify configuration and dependencies, unchanged.

## Deployment note
Deploy this source to the EXISTING Netlify site that currently contains the exercise-video Blobs. The video store is associated with the original Netlify site context; a different site does not automatically inherit those stored video files.
